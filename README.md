# 📊 Simple Dashboard

## 📖 Overview

This project is a responsive admin dashboard built as part of [The Odin Project's Intermediate HTML and CSS curriculum](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-admin-dashboard). It focuses on utilizing CSS Grid to create complex layouts, enhancing proficiency in modern CSS techniques.

## 🛠️ Features

* **Sidebar Navigation**: Provides easy access to different sections of the dashboard.
* **Header Section**: Includes search functionality and user profile information.
* **Main Content Area**: Displays project cards, announcements, and trending topics.
* **Responsive Design**: Ensures usability across various devices and screen sizes.
* **Iconography**: Utilizes SVG icons for visual enhancement.

## 🚀 Technologies Used

* **HTML5**: Structuring the dashboard's layout.
* **CSS3**: Styling the dashboard with a focus on CSS Grid for layout management.
* **SVG**: Incorporating scalable vector graphics for icons.

## 🎯 Getting Started

To view the dashboard locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/mubanga-1/simple-dashboard.git
   ```
2. Navigate to the project directory:

   ```bash
   cd simple-dashboard
   ```
3. Open `index.html` in your preferred web browser.
